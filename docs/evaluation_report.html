Iteration measured

Observed comparison, not a controlled accuracy experiment

Kept provisionally · judge prompt v2

The judge now requires one contiguous verbatim evidence quote in its original language and report metadata records the judge-prompt version. The archived v1 run had 1 PASS, 0 FAIL, 19 UNKNOWN; the v2 run has 18 PASS, 2 FAIL, 0 UNKNOWN. This removes the quote-validation UNKNOWN pattern, but it does not establish judge accuracy; current-v2 human TPR/TNR remain unavailable.

Abandoned · union original and translated retrieval queries

A trial that merged candidate articles from both queries scored 8/20 deterministic passes, compared with 11/20 in the pre-change v4 report. The wider context also coincided with citation regressions. The retrieval change was removed; retrieval remains on the translated keyword query. Because answer generation and keyword translation are model-driven, this run-to-run comparison is directional, not controlled.

Method and evidence

Reproducible inputs

Evaluation method

For each golden case, the app generates Portuguese retrieval keywords, retrieves legal articles from the cached source, produces a structured answer, then runs one judge call against that answer and the supplied excerpts. Deterministic checks compare expected article retrieval, citations, and abstention. A full 20-case run uses 20 cases and one judge assessment per answer; the application also makes translation and answer-generation calls.

Steering evidence and limits

Repository evidence, not a captured Copilot experiment

Two steering artifacts: root AGENTS.md directs all model calls through ask(), preserves prompt versions, and requires tests and abstention when excerpts do not support an answer. The reusable run-evaluation skill specifies the live evaluation procedure and cautions against treating automated checks as human review.

Evidence limitation: repository files show these rules and their intended application, but no before/after screenshot or same-request Copilot session comparison is available. No such evidence is claimed here.

Human-label limitation: the CSV has 20 reviewed drafts (18 PASS, 2 FAIL), but its drafts match the archived v1 trace, not the current v4 trace. Historical v1 TPR/TNR were computed only after matching those archived drafts. Re-review and label the current trace before claiming judge-v2 TPR/TNR.
