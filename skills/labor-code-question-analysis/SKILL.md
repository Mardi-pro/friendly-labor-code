# Skill: Labour Code Question Analysis

## Purpose

Complement the Labor Code Article Verification skill by clarifying what the
user is asking and carefully applying retrieved provisions to the facts given.
Use this skill for questions about rights, duties, procedures, or how a
provision applies to a particular situation.

## Analysis Steps

1. **Identify scope:** Determine whether the question concerns Portuguese
   labour law. If the jurisdiction is unclear or appears to be another
   jurisdiction, ask a brief clarifying question instead of assuming.
2. **Separate issues:** Break multi-part questions into distinct issues so each
   conclusion can be supported by its own relevant provision.
3. **Check material facts:** Identify facts that could change the answer. Ask
   one focused follow-up question when a material fact is missing; do not ask
   for names, identification numbers, or other unnecessary personal details.
4. **Apply, do not overstate:** Explain how the retrieved text relates to the
   facts the user provided. Distinguish what the provision expressly says from
   any plain-language explanation, and do not infer more than the text supports.
5. **State limits:** If the retrieved text is incomplete, does not resolve the
   issue, or does not support a reliable answer, say so plainly. Do not give a
   definitive assessment of an individual dispute or present the answer as
   formal legal advice.

## Response

- Answer directly and concisely, in the user's language when possible.
- Cite the exact article and the most specific paragraph or clause available
  for each legal conclusion.
- Explain any material uncertainty or missing fact; ask only the follow-up
  needed to resolve it.
